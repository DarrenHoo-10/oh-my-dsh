# Agent Note：为不支持图片输入的模型提供图片到文本中转

Status: implemented

[English](2026-08-16-image-to-text-relay.md) | 中文

## 问题

模型通过 `LlmModelInfo.inputModalities` 声明自己的输入模态；当路由模型未声明 `image` 时，宿主会拒绝带图 prompt。自定义提供方与 DeepSeek 目录都无法从 UI 声明图片支持，因此手工声明的视觉模型除非用户手改 `settings.yaml`，否则始终按纯文本对待。而对于确实不收图片的模型，拒绝是唯一结果——没有途径让另一个（具备视觉能力的）模型先看图，再给路由模型一份文本描述。

## 决策

三处改动一起发布：

1. **按模型的图片声明进入 UI 与两个适配器。** pi-ai 模型表单本就持久化 `input`；DeepSeek 目录新增同样的可选字段（`input?: ModelModality[]`，缺省或空表示仅文本），适配器将其暴露为 `inputModalities`，且当模型声明 `image` 且挂载了附件解析器时，其序列化器会把用户图片块携带为 OpenAI 兼容的 `image_url` data-URL 内容段。两个模型编辑器都渲染**支持图片**复选框，勾选存储 `['text', 'image']`，取消则移除该字段。
2. **可配置的图片理解模型把图片中转成文本。** 新的 `agent-vision-model` 设置命名空间（`provider`/`model` 成对，`maxOutputTokens` 默认 1024，`timeoutMs` 默认 30,000）选择中转路由。当路由模型未声明 `image` 时，prompt 准入用持久化图片块调用该模型，把用户自己的消息（含图片原样）写入表面会话，并记录一条仅模型可见的替换事件（`surfaceOp: replace` 覆盖原消息），内容为以 `【图片已由视觉模型理解】` 为前缀的描述文本。会话展示用户发送的原文与图片；模型看到中转文本；轨迹里两者（中转事件与替换事件）都可见。agent loop 会跳过准入监听器已记录的相同消息 id，避免 followup 重复追加。未配置时维持原有拒绝（`MODEL_DOES_NOT_SUPPORT_IMAGES`）；中转路由自身未声明 `image`，或中转调用失败／输出为空／出现工具调用时，以具名原因拒绝该 prompt。
3. **模型可见 ⟺ 已记录。** 中转分发在调用前记录一条 `session/vision-transcription` 事件（路由、系统提示、消息、token 上限），因此路由模型看到的描述文本可以从会话日志重建。系统提示是固定的常量；中转调用携带 `purpose: 'image-to-text'`。

DeepSeek 官方端点仅文本；其目录上的 `image` 是给该路由背后的自定义端点用的。`selectModel` 仅在配置了中转时允许把带图会话切换到纯文本模型；该会话的图片历史随后仍会重放给新模型并被适配器拒绝（延期工作）。

## 备选方案

**只在序列化器拒绝。** 若宿主准入不与声明一致，声明了图片的模型会在持久化消息之后才被适配器拒绝——这正是模态文档警告的过度声明陷阱。准入改动与序列化器改动一起发布。

**中转输出不带前缀。** 描述是模型可见文本；固定前缀标明它是中转产物，避免路由模型把它当成用户原话。曾考虑用户自定义提示词模板，最终延期：固定提示词让中转行为可预期、可重建。

## 影响

- 自定义视觉模型从 UI（复选框）或 `settings.yaml`（`input`）即可生效，pi-ai 与 DeepSeek 两条路由皆可。
- 向纯文本模型发送带图 prompt，要么经配置的图片理解模型中转，要么以与之前相同的原因被拒绝。聊天记录保留用户自己的图片与文字；中转描述仅模型可见，并出现在轨迹中。
- 触发中转时会多花一次模型调用与相应 token；路由模型接受图片时绝不触发。
- DeepSeek 序列化器变为异步（需要读取图片），其用户消息线格式可能变为内容段数组；纯文本请求保持原有字符串线格式。
- agent loop 现在会跳过日志中已存在的相同消息 id（每条消息 id 在会话中只有一个家），这正是准入监听器可以预置原文与其模型专用替换的依据。
- `generate_image` 工具（由 agent preset 挂载）复用同一个图片理解选择作为生成路由：普通路由走 OpenAI 兼容的 `/v1/images/generations`，MiniMax 的 anthropic-messages 路由走其原生 `/v1/image_generation`，无法生成时大声失败。结果保存进会话工作区，并以路径形式返回给模型，因此纯文本主模型无需看到字节即可产出图片。
