# Agent Note: 跟随用户语言

Status: implemented

[English](2026-08-15-follow-user-language.md) | 中文

## 问题

内置 UI 语言只影响客户端文案，不会进入模型上下文。因此，模型收到的系统指令和工具说明以英文为主，可能用英文回答中文消息，或者展示英文推理摘要与工具调用描述。

## 决策

所有内置部署 persona 和 agent preset persona 都要求模型对全部自然语言输出使用用户最新一条消息的语言，除非用户指定其他语言。该指令涵盖推理摘要和工具调用描述，同时保留代码、命令、标识符、路径和引文的原始形式。

这条规则属于内置 persona，而不属于客户端语言设置。因此，它无需将模型行为耦合到某一种展示客户端，就能一致应用于 Web、桌面、headless、恢复的会话、fork 和侧边聊天。用户自定义 persona 仍具有最终决定权，可以替换这条规则。

## 验证

无需密钥的 Web minimal preset 快照断言模型实际收到的完整组装提示词。组合检查覆盖桌面对 Web 组合包的叠加关系，聚焦配置检查则固定所有内置 persona 中的相同指令。

## 考虑过的替代方案

**把 UI 语言发送给模型。** 这种方式会把界面偏好强加给多语言对话，并且模型可见输入必须被记录，因此还需要新增持久化会话状态。

**在客户端翻译模型输出。** 后处理可能破坏代码、命令、路径和引文，也无法在生成期间纠正模型的语言选择。

**只在桌面组合包中应用规则。** 桌面和 Web 会继续产生差异，而且 agent 作用域 persona 会遮蔽桌面部署 persona。

## 后果

内置 persona 默认跟随用户语言，无需新增设置或改变会话格式。混合语言消息仍依赖模型对最新消息的判断，而且模型提供方可能无法完全服从该指令。
